# ORBE — site

## Como usar
1. Abra `index.html` no navegador para visualizar o site.
2. Abra `script.js` e troque `WHATSAPP_NUMBER` pelo WhatsApp oficial da empresa.
3. Troque o e-mail e o Instagram no rodapé.
4. Se quiser domínio próprio, hospede os três arquivos (`index.html`, `style.css`, `script.js`) em um serviço de hospedagem.
5. Antes de publicar, revise preços, serviços, contatos e termos comerciais.

## Estrutura
- `index.html` — conteúdo e estrutura.
- `style.css` — visual responsivo.
- `script.js` — menu mobile e botões de WhatsApp.

## Observação
O site foi construído sem depender de WordPress, Wix, Framer ou outro construtor. Ele pode ser hospedado como um site estático.
